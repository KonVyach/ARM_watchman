Настольное приложение для автоматизации контроля доступа по лицу на входе в учреждение. Проводит человека через настраиваемую цепочку проверок: распознавание лица →
металлодетектор → температура → содержание алкоголя/опьянения → турникет.

Аппаратное обеспечение (тепловиктор, металлодетектор, алкотестер, турникет) абстрагировано за
небольшими интерфейсами на C++ и поставляется с программными макетами, управляемыми с панели управления в пользовательском интерфейсе. Веб-камеры реальные (OpenCV `VideoCapture`).

## Стек

- C++17 + Qt6 (виджеты, SQL, мультимедиа)
- OpenCV 4 — захват с камеры + распознавание лиц (`cv::FaceDetectorYN`)
- ONNX Runtime (C++) — встраивание лиц ArcFace
- SQLite3 — локальная база данных пользователей и журнал аудита

## Сборка

```bash
# 1. Получите ONNX Runtime (предварительно собранный, любой релиз 1.16+):
# https://github.com/microsoft/onnxruntime/releases
# Распакуйте куда-нибудь, например, ~/onnxruntime-osx-arm64-1.18.0/

# 2. Получите OpenCV (с моделью face_detection_yunet):
# macOS: brew install opencv
# Ubuntu: apt install libopencv-dev

# 3. Получите модель InsightFace ArcFace (одноразовая):
# Загрузите `buffalo_l` с https://github.com/deepinsight/insightface
# Поместите `w600k_r50.onnx` в third_party/models/arcface.onnx
# Поместите модель детектора YuNet в third_party/models/yunet.onnx
# (например, https://github.com/opencv/opencv_zoo/tree/main/models/face_detection_yunet)

# 4. Настройте и соберите
cmake -S . -B build \

-DONNXRUNTIME_DIR=$HOME/onnxruntime-osx-arm64-1.18.0
cmake --build build -j

# 5. Запуск
./build/facecontrol
```

## Первый запуск

- Пустая база данных SQLite создается по адресу `~/.facecontrol/facecontrol.db`.

- Пароль администратора по умолчанию — `admin` — измените его при первом входе в систему.

- Откройте вкладку **Администрирование** → войдите в систему → **Добавить человека**, чтобы зарегистрировать пользователей.

- Перейдите на вкладку **Контроль**, чтобы запустить контрольную точку.


## Моделирование оборудования

Правый **Пульт симулятора** позволяет вручную управлять всеми устройствами, кроме камер:
- ползунок температуры (°C),
- флажок срабатывания металлодетектора,
- ползунки уровня алкоголя в крови и оценки наркотического опьянения,
- кнопка «человек прошел через турникет».

Для подключения реального оборудования реализуйте соответствующий интерфейс в
`include/facecontrol/hardware/` (`IThermalSensor`, `IMetalDetector`, `IBreathalyzer`,
`ITurnstile`) и поменяйте регистрацию в `DeviceManager::createDefault`.

## Примечания к адаптивному порогу

Сопоставитель лиц начинает работу с порогом косинусного сходства `0,45`. Каждый раз, когда охранник
подтверждает, что лицо, которое модель не смогла распознать, *действительно* присутствует в базе данных,
пороговое значение снижается на `0,02`, до минимального значения `0,30`. Текущее значение сохраняется
в таблице `settings`.
